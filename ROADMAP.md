# Дорожная карта

Даты уточняются по готовности. GitHub Issues хранят критерии задач, milestones показывают этапы, GitHub Project объединяет задачи в Board, Table и Roadmap.

| Этап | Проверяемый результат |
| --- | --- |
| Stage 0 — Foundation | Публичный репозиторий, стартовая документация, задачи, milestones, labels, GitHub Project и защита main |
| v0.1.0 — Прототип CLI | Синтетический тест и один подтверждённый сценарий проверки через Xray-core из домашнего DEV LXC |
| v0.2.0 — История проверок | Ручной импорт VLESS (#11), SQLite (#12), опрос (#13), числовой снимок (#14). История переживает перезапуск и возврат узлов |
| v0.3.0 — Веб-панель | Таблица числовых показателей, фильтры, приватные настройки и копирование VLESS; без графиков и рейтингов |
| v0.4.0 — Установка и выпуск | Документированная установка в Linux LXC и воспроизводимая сборка на синтетических данных |

Лицензия проекта — [Apache-2.0](LICENSE), утверждена владельцем (см. [ADR 0002](docs/decisions/0002-project-license.md)). До первого выпуска необходимо определить способ поставки зависимостей и проверить лицензионные условия выбранной версии Xray-core.

Последовательность: #3 CLI → #4 Go CI → #5 (подзадачи #11–#14) → #6 веб-панель → #7 выпуск. Обновление подписок только вручную; тесты скорости не входят в объём первой версии.

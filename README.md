# HomeVPN Monitor

HomeVPN Monitor — автономный сервис для проверки VPN-узлов из домашней сети и просмотра истории их доступности в веб-панели. Проект находится на этапе подготовки. Установочной версии пока нет.

Сервис будет выполнять проверки в домашнем DEV LXC через Xray-core и хранить результаты локально в SQLite. Веб-панель покажет состояние узлов, задержку и историю. Оператор самостоятельно выбирает узел и переносит его настройку в HydraRoute. VPS используется только как reverse proxy веб-панели.

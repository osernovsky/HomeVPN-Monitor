# Разработка HomeVPN Monitor

GitHub хранит исходники, документацию и задачи. Рабочая среда для сетевых экспериментов — домашний DEV LXC. Подключение графического Codex к DEV по SSH и авторизация Git в контейнере проверяются отдельно.

## Работа над задачей

1. Открой GitHub Issue, уточни критерии приёмки и создай отдельную ветку от main.
2. Работай с синтетическими примерами. При разделении параллельной работы используй отдельные рабочие деревья Git.
3. Для Go-кода после появления модуля запускай форматирование, go vet ./... и go test ./.... Для реальной VPN-проверки используй только домашний DEV LXC.
4. Проверь дифф на рабочие подписки, ключи, адреса, базы и журналы. Укажи в pull request проверенные сценарии и среду выполнения. Слияние выполняет владелец.

## Границы сред

| Среда | Допустимые действия |
| --- | --- |
| Домашний DEV LXC | Разработка, синтетические тесты и реальные проверки VPN |
| GitHub Actions | Проверка документации, затем сборка Go и тесты с синтетическими данными |
| VPS | Reverse proxy веб-панели |

Секреты и файлы рабочего состояния хранятся локально вне рабочего дерева Git. Для будущих синтетических сетевых тестов используй заглушки или loopback. Доступ и маршрутизацию DEV проверяют перед первым запуском с рабочей подпиской.

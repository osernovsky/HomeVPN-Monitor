# ADR 0001. Основной язык программирования — Go

**Статус** — утверждено.  
**Дата** — 27 ноября 2026 года.

## Контекст

HomeVPN Monitor — долгоживущий сервис для Linux. Он параллельно выполняет сетевые проверки, соблюдает тайм-ауты, управляет отдельным процессом Xray-core, сохраняет статистику в SQLite и обслуживает веб-панель.

## Решение

Использовать Go для серверной части, планировщика, адаптера Xray-core и слоя хранения. Стандартная библиотека покрывает HTTP, управление процессами и отмену операций. Горутины подходят для параллельных проверок с ограничением нагрузки. Сборка исполняемых файлов для Linux упрощает установку в LXC. Простота кросс-компиляции зависит от выбранных зависимостей и использования CGO.

Для первой интеграции Xray-core запускается как отдельный процесс. Выбор драйвера SQLite и способ поставки Xray-core остаются отдельными решениями.

## Рассмотренные варианты

| Язык | Оценка для проекта |
| --- | --- |
| Python | Удобен для прототипов. Для поставки сервиса потребуется управлять средой исполнения или упаковывать её. |
| Rust | Даёт строгий контроль ресурсов. Для первой версии увеличивает объём освоения и разработки. |
| TypeScript и Node.js | Подходят для задач ввода-вывода. Поставка серверной части потребует отдельной среды исполнения или её упаковки. |

## Последствия

В тестах планировщика проверяем тайм-ауты, отмену и завершение фоновых задач. Интерфейс может использовать HTML, CSS и JavaScript.

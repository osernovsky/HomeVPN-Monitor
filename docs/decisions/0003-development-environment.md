# ADR 0003. Локальный Codex и удалённая среда разработки

**Статус** — утверждено.  
**Дата** — 27 ноября 2026 года.

## Контекст

Реальные VPN-проверки должны выполняться из домашней сети без exit node и без правил HydraRoute, которые могли бы искажать измерения. Запуск удалённого Codex App Server потребовал бы доступа DEV к OpenAI, который в данной среде ограничен.

## Решение

Использовать локальное графическое приложение Codex и штатный OpenSSH для выполнения команд в домашнем DEV LXC. Референсная среда — Ubuntu 24.04 LTS (amd64). GitHub является источником кода; локальная рабочая копия используется для редактирования и авторизованной записи, DEV — для сборки и проверок. Публичный репозиторий читается с DEV без токенов записи. Не устанавливать Codex CLI на DEV и не добавлять сторонний SSH MCP-сервер.

Сохранять доступ по приватному пути, использовать отдельного непривилегированного пользователя и отдельные ключи рабочих компьютеров, без SSH agent forwarding. Не публиковать сведения о реальных адресах, ключах, подписках и журналах. VPS остаётся исключительно reverse proxy.

## Приёмка

По отчёту Codex и владельца успешен неинтерактивный вход через OpenSSH с macOS, проверены права рабочего каталога, доступ GitHub по HTTPS и совпадение внешнего IPv4 контрольного запроса DEV с домашним клиентом. Владелец подтвердил исключение из HydraRoute и завершение подготовки DEV, включая инструменты и проверку Git. Подробный финальный вывод команд не приложен; версии инструментов и состояние SSH-защиты отдельно проверить при начале прототипа. Windows-подключение не проверено и не блокирует работу с macOS.

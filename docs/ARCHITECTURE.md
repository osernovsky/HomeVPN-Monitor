# Архитектура HomeVPN Monitor

Go-сервис работает в домашнем DEV LXC. Он вручную обновляет снимки подписок по действию оператора, управляет периодическим опросом, вызывает Xray-core как отдельный процесс, записывает результаты в SQLite и обслуживает числовую веб-панель. Для первой версии рассматривается интерфейс на HTML, CSS и JavaScript с JSON API.

| Компонент | Ответственность |
| --- | --- |
| Импорт подписок | Ручная HTTPS-загрузка, разбор VLESS/plain/Base64, классификация, стабильная идентичность и сверка снимка |
| Планировщик | Прямой контроль, настраиваемый интервал, параллельность, тайм-ауты, отмена и непересекающиеся циклы |
| Адаптер Xray-core | Запуск и остановка отдельного процесса, получение результата проверки |
| SQLite | Подписки, узлы с active/inactive, накопительные счётчики и измерения за 7 суток; статистика отдельно по HTTPS-цели |
| Веб-панель | Числовая таблица активных узлов, ручное обновление, приватные настройки и копирование ссылки |
| VPS | Reverse proxy для удалённого просмотра разрешённых данных панели |

Проверочный трафик выходит из дома через проверяемый узел. У DEV LXC должен быть обычный домашний маршрут без VPS в роли exit node. Контейнер не включается в правила маршрутизации, предназначенные для HydraRoute. Секретные операции и рабочие настройки доступны по приватному пути к DEV LXC. Reverse proxy получает только разрешённую для просмотра часть панели.

Интеграция с Xray-core через отдельный процесс упрощает обновление и изолирует сбои сетевого ядра. Референсная версия Xray-core фиксируется в руководстве по разработке. Форматы импорта — VLESS URI построчно и Base64. Драйвер SQLite выбирается в #12. [ADR 0001](decisions/0001-programming-language.md) фиксирует выбор Go.

Прямой контроль и проверка через VPN используют независимо настраиваемые HTTPS-цели (по умолчанию https://yandex.ru/internet/). Выполняется лёгкий GET до заголовков с проверкой TLS, без тестов скорости. Отдельная прямая контрольная проверка не проходит через Xray. Если контроль неуспешен, цикл пропускается без начисления отказов. Подробнее — [спецификация](SPECIFICATION.md).

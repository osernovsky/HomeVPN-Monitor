# Архитектура HomeVPN Monitor

Go-сервис работает в домашнем DEV LXC. Он управляет очередью проверок, вызывает Xray-core как отдельный процесс, записывает результаты в SQLite и обслуживает веб-панель. Для первой версии рассматривается интерфейс на HTML, CSS и JavaScript с JSON API.

| Компонент | Ответственность |
| --- | --- |
| Импорт подписок | Загрузка, разбор и сопоставление узлов с локальной историей |
| Планировщик | Очередь, лимит параллельности, тайм-ауты и отмена проверок |
| Адаптер Xray-core | Запуск и остановка отдельного процесса, получение результата проверки |
| SQLite | История проверок и служебные данные, необходимые для их отображения |
| Веб-панель | Состояние узлов, история и ручной выбор настройки |
| VPS | Reverse proxy для удалённого просмотра разрешённых данных панели |

Проверочный трафик выходит из дома через проверяемый узел. У DEV LXC должен быть обычный домашний маршрут без VPS в роли exit node. Контейнер не включается в правила маршрутизации, предназначенные для HydraRoute. Секретные операции и рабочие настройки доступны по приватному пути к DEV LXC. Reverse proxy получает только разрешённую для просмотра часть панели.

Интеграция с Xray-core через отдельный процесс упрощает обновление и изолирует сбои сетевого ядра. Версию Xray-core, формат подписки и драйвер SQLite предстоит выбрать по итогам прототипа. [ADR 0001](decisions/0001-programming-language.md) фиксирует выбор Go.

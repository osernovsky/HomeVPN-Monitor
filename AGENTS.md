# Инструкции для работы над HomeVPN Monitor

Начинай с GitHub Issue и сверяйся со [спецификацией](docs/SPECIFICATION.md), [архитектурой](docs/ARCHITECTURE.md) и [дорожной картой](ROADMAP.md). Основной язык — Go. Для изменений используй отдельную ветку и pull request. Слияние выполняет владелец проекта после приёмки.

- Реальные проверки VPN запускай исключительно в домашнем DEV LXC. Для них используй только предоставленные оператором подписки и разрешённые тестовые адреса.
- VPS используется исключительно как reverse proxy веб-панели. Эксперименты, сборка и VPN-проверки выполняются в других средах согласно [руководству по разработке](docs/DEVELOPMENT.md).
- Перенос настройки в HydraRoute выполняет оператор вручную. Изменения конфигурации роутера и HydraRoute через приложение исключены.
- Используй синтетические данные в GitHub Actions, документации и публичных примерах. Храни подписки, рабочие конфигурации, ключи, базы и журналы локально. Перед публикацией проверяй дифф и вложения на секреты.
- Указывай в pull request выполненные проверки и их среду. Реальные результаты описывай без идентификаторов, адресов и конфигураций.

На этапе фундамента работа ограничена документацией и инфраструктурой GitHub.
